**An interactive 3D portfolio built with React, Three.js, and Framer Motion.**  
[Live Demo](https://ryanhui-portfolio.vercel.app/) | [Source Code](https://github.com/ryanhui30/portfolio-3d)

---

## ✨ **Key Features**  
- **Immersive 3D Elements**:  
  - Floating laptop/smartphone models that track cursor movement  
  - Particle background with animated tech icons (React Three Fiber)  
- **Dynamic Content**:  
  - Projects displayed in an interactive 3D carousel  
  - Skills visualized as rotating 3D spheres  
- **Functional Contact Form**:  
  - EmailJS integration with responsive validation  

---

## 🛠 **Tech Stack**  
| Category       | Technologies Used                          |
|----------------|-------------------------------------------|
| **Frontend**   | React, Three.js, React Three Fiber        |
| **Animation**  | Framer Motion, GSAP                       |
| **Styling**    | Tailwind CSS                              |
| **Backend**    | EmailJS (contact form)                    |
| **Deployment** | Vercel                                    |

## 🖥️ **Local Setup**  
  ```bash
  git clone https://github.com/ryanhui30/portfolio-3d.git
  cd portfolio-3d
  npm install
  npm run dev
  ```

# Clone repository
  ```bash
  git clone https://github.com/ryanhui30/portfolio-3d.git
  cd portfolio-3d
  ```

# Install dependencies
  ```bash
  npm install
  ```

# Configure environment variables
```cp .env.example .env```

# Add your EmailJS credentials

# Run development server
  ```bash
  npm run dev
  ```
